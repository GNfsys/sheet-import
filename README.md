# Sheet Import

### A simple php wrapper for LibreOffice that uses `league/csv` to handle basic spreadsheet reading

This is a work in progress.

See [USAGE.md](USAGE.md) for usage.

## Credits

- Took some inspiration from [Laravel Excel](https://github.com/SpartnerNL/Laravel-Excel)
- Uses [`league/csv`](https://github.com/thephpleague/csv), [`bakame/html-table`](https://github.com/bakame-php/html-table), `symfony/process` under the hood
